# ECHO VAULT — 시간의 금고

과거의 움직임을 기록하고, 세 잔상이 현재의 금고를 열도록 설계하는 시간 루프 퍼즐입니다.

[게임 실행](https://hyungminyoon1.github.io/echo-vault/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/) · [소스](https://github.com/HyungminYoon1/echo-vault)

## 게임

- 12개 금고와 4개 장. 잠금 충전, 동시 압력판, 순서 코어와 서로 다른 주기 레이저를 조합합니다.
- 반복당 15초(60박자). 실시간 기록 또는 일시정지 상태에서 한 박자 계획이 가능합니다.
- 최대 3개 잔상은 기록된 경로를 재생하고 마지막 위치를 유지합니다. 코어 회수와 레이저 판정은 현재 기체에만 적용합니다.
- 64개 상태까지 한 박자 취소. 같은 잔상으로 재시도하거나 마지막 잔상을 제거할 수 있습니다.
- 기본 진입은 7번 복합 금고. 금고 선택에서 1번부터 학습하거나 모든 캠페인으로 이동할 수 있습니다.
- 힌트는 성공 점수에서 300점을 차감하며 되감기/재시도/취소로 감점이 사라지지 않습니다.

## 조작

WASD/방향키 이동, Space 대기, P 실시간 시작/정지, R 기록 후 되감기, Z 한 박자 취소. 방향 패드로 같은 명령을 실행할 수 있습니다.

## 규칙과 기록

문 진입은 박자 시작의 잠금 상태를 사용하고, 이동·잔상 재생 이후 점유/충전을 갱신합니다. 떠난 압력판의 충전은 즉시 0입니다. 현재 기체의 레이저/코어 순서/출구를 판정한 뒤 60박자 제한을 적용합니다. 시간 종료 경로는 잔상으로 보관할 수 있지만 레이저/순서 실패는 보관할 수 없습니다.

성공 점수 = max(0, 3000 − 박자×20 − 잔상×150 − 힌트×300). 기록은 현 페이지 메모리만 사용합니다.

0.25초 고정 박자, 반복당 최대 60, 잔상 3×61 위치, 취소 64 상태, 캠페인/최고 기록 12개. 실시간 프레임당 최대 4박자까지 처리하고 긴 지연은 버립니다.

상태·최고 기록·설정은 현재 페이지 메모리에만 남으며 탭을 닫으면 사라집니다. 계정, 쿠키, 영구 저장, 전체 사용자 순위, 분석 도구, 서버 API 또는 자동 소리 재생은 없습니다. GitHub 호스팅 로그는 앱의 저장 기능과 별개입니다. 외부 폰트/이미지/패키지 없이 직접 그린 Canvas/SVG/CSS 아트를 사용합니다.

## 실행 및 배포

Node.js 22 이상. 외부 패키지를 설치하지 않습니다.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 127.0.0.1에서 dist만 제공합니다. main의 Pages 워크플로가 테스트와 공개 파일 검사를 통과한 뒤 dist만 배포합니다. 공개 소스는 GitHub Actions입니다.

## 검증

20 model tests: 12개 캠페인 실제 규칙 해답, 충전/닫힌 문/벽/코어 순서/레이저/60박자 경계/기록/재시도/점수와 입력 검증.

1/7/12의 일반 키보드 이동·기록 버튼으로 실제 탈출 및 2490/1810/1770점 일치를 확인했습니다. 방향 패드, 한 박자 취소, 힌트 감점의 기록/재시도 유지와 실시간 정지 후 시계 동결을 확인했습니다.

모델은 12개 모두 검증했고, 브라우저 완주는 1/7/12를 선택하여 확인했습니다. 390/320px에서는 내부 보드 스크롤, 도움말/선택 메뉴와 조작을 검토합니다. 실제 모바일 하드웨어, 모든 브라우저 및 사람의 난도/재미 평가는 별도 확인이 필요합니다. 원격 CI와 실제 공개 결과는 [최신 통합 공개 검증](https://github.com/HyungminYoon1/web-lab/blob/main/docs/verification.md)을 확인하세요.

AI 에이전트와 제작한 독립 단일 플레이 게임입니다. 기존 서비스 코드는 병합하지 않습니다. UTF-8 without BOM / CRLF.
