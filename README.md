# ECHO VAULT — 시간의 금고

이동을 기록하고 되감아, 잔상과 함께 문을 여는 시간 퍼즐입니다.

[게임](https://hyungminyoon1.github.io/echo-vault/) · [WEB LAB](https://hyungminyoon1.github.io/web-lab/) · [소스](https://github.com/HyungminYoon1/echo-vault)

## 게임과 조작

첫 방문은 짧은 입문 금고입니다. 기존 V1 금고 1–12를 보존하고 V2 시간 회로 13–15를 추가했습니다. 모든 금고를 바로 선택할 수 있습니다.

- 방향키/WASD: 이동. Space: 대기. 정지 중에는 한 박자씩 진행합니다.
- R: 기록·되감기. 잔상은 경로를 재생한 뒤 마지막 칸을 유지합니다. 최대 3개입니다.
- P: 실시간 시작·정지. Z: 한 박자 취소, 최대 64개 상태.
- 화면 버튼으로도 동일하게 조작합니다. 기본 보드는 전체 보기이며, 확대하면 내부 스크롤로 이동할 수 있습니다.
- 반복 재시도는 잔상을 유지합니다. 잔상 삭제는 마지막 기록을 제거합니다.

문 진입은 박자 시작 상태를 사용합니다. 이동·잔상 재생 후 압력판 충전을 갱신하고, 떠난 압력판의 충전은 0이 됩니다. 그다음 시간 회로, 레이저, 코어 순서, 출구를 판정합니다. 현재 기체만 코어를 회수하고 레이저에 감지됩니다. 1박자는 0.25초, 반복은 최대 60박자입니다. 시간 종료 경로는 잔상으로 보관할 수 있고 다른 실패 경로는 보관할 수 없습니다.

13–15번은 필요한 잔상 2/2/3개를 만든 뒤 시간 회로가 작동합니다. 표시된 구간 안에서 잔상만 지정 압력판을 연속으로 누르거나 해제해야 합니다. 13번은 A 재방문, 14번은 A/B 교대와 코어 순서, 15번은 A/B/C 교대와 재집결·코어·레이저를 결합합니다. 회로를 모두 마치고 문을 유지한 채 출구 시간에 도착해야 합니다.

개인 점수 = max(0, 3000 − 박자×20 − 잔상×150 − 힌트×300). 힌트 감점은 되감기·재시도·취소로 지워지지 않습니다.

## 저장

진행·잔상·개인 최고 점수는 이 브라우저에 자동 저장됩니다. 재방문 시 **이어하기**로 정지 상태에서 복원합니다. 다른 금고를 시작하면 현재 진행 저장이 교체됩니다. **기록 삭제**는 이 게임의 저장과 갤러리 완주 요약만 지웁니다. 취소 이력은 현재 세션에만 남습니다.

- `echo-vault-save-v1`: 저장 형식 1 / 캠페인 2. 현재 기록 1개와 금고별 최고·독립 완주 입력 증거 최대 30개. 최대 131072 UTF-16 코드 단위(256 KiB). 각 반복 60입력, 잔상 3개. 좌표·점수를 신뢰하지 않고 실제 모델로 재실행합니다.
- `web-lab-progress-v1`: 15개 허용 앱의 `completed`, `total`, `updatedAt`만 보관하는 최대 8192자 요약. 이 게임은 입문을 제외한 15개 중 힌트 없이 실제 완주한 금고 수를 기록합니다. 갤러리는 개인 경로나 점수에 접근할 필요가 없습니다.

저장 거부·용량 부족 시 현재 탭에서 계속 플레이할 수 있으며 저장 실패를 표시합니다. 잘못된 버전이나 손상된 저장은 불러오지 않습니다. 계정·서버·공개 순위·분석 도구는 없습니다. 같은 출처의 페이지는 브라우저 저장 영역을 공유하며, 브라우저 데이터 삭제 시 기록도 사라집니다.

## 개발과 검증

Node.js 22 이상, 패키지 설치 없이 실행합니다.

```sh
npm run dev -- 0
npm test
npm run check
```

개발 서버는 `127.0.0.1`에서 `dist`만 제공합니다. 모델 해답은 `tools/witnesses.mjs`에 있으며 공개 앱은 가져오지 않습니다. 기존 12개와 새 3개 금고·입문 해답, 시간 제약 실패, 저장 재실행·손상·경계, 공용 요약 보존을 테스트합니다. 공개 파일 검사는 네트워크 금지, 저장 경계, CSP, 문법·참조·DOM 연결, UTF-8 without BOM / CRLF를 확인합니다.

이번 변경의 실제 브라우저 조작·스크린샷·배포는 통합 담당자가 확인합니다. 로컬 모델 결과와 과거 V1 브라우저 결과는 구분합니다. [검증 기록 및 실제 조작 순서](docs/verification.md) · [구조](architecture.md) · [요구사항](requirements.md) · [결정](docs/decisions.md)
