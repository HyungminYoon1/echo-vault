# 2026-10-13 학습 과제의 근거

과제 13–15는 기존 저작 캠페인의 시간 창·누름/해제·코어/레이저 조건을 읽는 연습이다. 새 임의 배치나 정답 자동 기록을 만들지 않았다. 시간표는 실제 저장된 잔상의 경로와 마지막 위치 유지에서 계산한다.

- 규칙의 1차 근거: [모델](../dist/src/model.js)의 echoPosition/advanceRelay/echoSchedule, [캠페인](../dist/src/levels.js)의 13–15번.
- 실행 근거: [회귀·시간 구간 검증](../test/relay.test.js), [합법 입력 증거](../tools/witnesses.mjs)의 relayWitnesses/relayExitWitness.
- 스스로 비교할 과제 문구와 한국어 설명은 이번 작업의 원문이다. 자동으로 힌트를 보거나 기록을 생성하지 않는다.
